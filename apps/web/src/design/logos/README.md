RawJobs logos. Lowercase **rawjobs** in Geist Mono 500, outlined to paths, followed by a solid signal block cursor (#ff5a1f). No font needed to display them.

- `rawjobs-wordmark-ink.svg`: ink (#151412) letters, for `bg-canvas` and `bg-raised` in the light themes.
- `rawjobs-wordmark-paper.svg`: paper (#f5f1e8) letters, for the dark themes.
- `rawjobs-mark.svg`: the cursor on an ink square. App icon, favicon, social avatar.

Clear space: the cursor's width on every side. Minimum wordmark width 96px; below that use the mark. Never recolor the cursor, add a tagline inside the lockup, or animate it in the product. Two exceptions: on the not-running pages the cursor in the app icon fills like a battery while RawJobs starts (`design/README.md`, Motion), and on the marketing site the intro blinks it.
